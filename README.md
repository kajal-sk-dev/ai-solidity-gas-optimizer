# AI Solidity Gas Optimizer
AI tool to analyze and optimize gas usage in Solidity smart contracts.

## Features
- Gas analysis
- Optimization suggestions
- Streamlit UI

## Run
pip install -r requirements.txt
streamlit run app.py
